三個定理都是同一邏輯的不同維度版本：在某個範圍的邊界上量出來的總量，等於這個範圍內部某種微分量的積分總和。

Null Identity（兩個恆等於零的關係式）

恆等式一
$\nabla\times(\nabla V)=0$
梯度場永遠無旋 → 這是保守場（電場、重力場）可以定義位能的數學基礎。
恆等式二
$\nabla\cdot(\nabla\times\vec A)=0$
旋度場永遠無散 → 這是磁場 $\nabla\cdot\vec B=0$（無磁單極）的數學基礎。

算子為 0 時的英文特別名稱

條件英文名稱意義
$\nabla V=0$ critical point
stationary point		 臨界點／駐點；若 $V$ 是位能，也稱 equilibrium point（平衡點）
$\nabla\cdot\vec A=0$ solenoidal field 螺線場／無源場，也稱 divergence-free field 或 incompressible field（流體力學脈絡）；磁場 $\vec B$ 永遠是 solenoidal

Gradient 梯度

$\nabla V$  ·  純量場 → 向量
口語定義

某一點的梯度，是一個向量，指向這個純量場（比如溫度、高度、電位）上升最快的方向，大小代表這個上升速率有多快。

原始定義（方向導數）
$$\nabla V\cdot\hat a_\ell=\frac{dV}{d\ell}\Big|_{\max}$$

某方向上 $V$ 的變化率，在梯度方向上達到最大值。

卡氏座標公式 / 計算方式
$$\nabla V=\hat a_x\frac{\partial V}{\partial x}+\hat a_y\frac{\partial V}{\partial y}+\hat a_z\frac{\partial V}{\partial z}$$

拿純量函數 $V(x,y,z)$，分別對 $x,y,z$ 做偏微分，結果依序當作向量的 $x,y,z$ 分量。不需要行列式，是三者中最單純的計算。

物理意義
  • 地形圖：$V$ = 海拔高度，$\nabla V$ = 最陡上坡方向，大小 = 坡度
  • 溫度場：$V$ = 溫度，$\nabla V$ = 升溫最快的方向
  • 靜電場：$\vec E=-\nabla V$，電位下降最快的方向就是電場方向（負號代表電場指向電位降低處）
數學意義

梯度把「純量場的變化趨勢」轉換成一個向量，包含方向與大小兩種資訊。等值面（等溫線、等高線）上，梯度永遠垂直於等值面。

跟另外兩者的關聯
$\nabla\times(\nabla V)=0$（null identity 之一）

梯度場永遠無旋，代表梯度場是保守場（conservative field），繞封閉路徑一圈作功為 0。

保守場 無旋

Divergence 散度

$\nabla\cdot\vec A$  ·  向量場 → 純量
口語定義

某一點的散度，是一個純量，代表這一點是不是「源頭」（往外冒東西，正值）或「凹陷」（往內吸東西，負值）。數值大小代表冒出/吸入的強度。

原始定義（通量密度）
$$\nabla\cdot\vec A=\lim_{\Delta V\to0}\frac{\oint_S\vec A\cdot d\vec S}{\Delta V}$$

一個無窮小封閉曲面的淨通量，除以體積，取極限。

卡氏座標公式
$$\nabla\cdot\vec A=\frac{\partial A_x}{\partial x}+\frac{\partial A_y}{\partial y}+\frac{\partial A_z}{\partial z}$$

$A_x$ 對 $x$ 微分、$A_y$ 對 $y$ 微分、$A_z$ 對 $z$ 微分，三項加起來。不需要行列式。

推導邏輯（簡述）

以某點為中心畫一個無窮小長方體，六個面兩兩一組。每一對面，右（前/上）面的值減左（後/下）面的值，除以邊長，取極限就是偏導數。三個方向獨立算完直接相加——因為通量本質是法向量往外穿出曲面，同方向的分量自己變化多少就直接算多少，不需要跟其他方向互相牽制。

柱座標 / 球座標版本
柱座標
$$\nabla\cdot\vec A=\frac{1}{r}\frac{\partial(rA_r)}{\partial r}+\frac{1}{r}\frac{\partial A_\phi}{\partial\phi}+\frac{\partial A_z}{\partial z}$$
球座標
$$\nabla\cdot\vec A=\frac{1}{R^2}\frac{\partial(R^2A_R)}{\partial R}+\frac{1}{R\sin\theta}\frac{\partial(\sin\theta A_\theta)}{\partial\theta}+\frac{1}{R\sin\theta}\frac{\partial A_\phi}{\partial\phi}$$
物理意義
  • 流體力學：$\vec A$ = 流速場，$\nabla\cdot\vec A>0$ 代表這裡有「湧泉」，$<0$ 代表「排水孔」，$=0$ 代表不可壓縮流
  • 靜電場：$\nabla\cdot\vec E=\rho/\epsilon_0$（高斯定律微分形式），電荷密度 $\rho$ 是電場線的源頭
  • 磁場：$\nabla\cdot\vec B=0$ 恆成立，因為沒有磁單極，磁力線永遠閉合
數學意義

散度衡量向量場在某一點的「發散程度」，是純量（沒有方向性），因為通量本質上不分方向，只問淨流出多少。

對應的積分定理：散度定理（高斯定理）
$$\oint_S\vec A\cdot d\vec S=\int_V(\nabla\cdot\vec A)\,dV$$

封閉曲面的淨通量，等於內部散度的體積分總和——邊界（2維曲面）上量到的東西，等於內部（3維體積）微分量的積分。

跟另外兩者的關聯
$\nabla\cdot(\nabla\times\vec A)=0$（null identity 之二）

旋度場永遠無散，因為旋度場天生是閉合迴圈（像磁力線），沒有起點終點，自然沒有淨的冒出或吸入。

閉合迴圈

Curl 旋度

$\nabla\times\vec A$  ·  向量場 → 向量
口語定義

某一點的旋度，是一個向量，代表這一點附近的場會不會讓一個小紙風車轉起來。轉軸方向就是旋度向量的方向（右手定則：四指順著轉動方向彎，拇指指的就是旋度方向），轉得越快，旋度大小越大。

原始定義（環流密度）
$$(\nabla\times\vec A)_u=\lim_{\Delta S\to0}\frac{\oint_C\vec A\cdot d\vec\ell}{\Delta S_u}$$

某方向 $u$ 的旋度分量，是垂直於 $u$ 方向的一個無窮小迴路，其環流量除以迴路面積，取極限。

卡氏座標公式（行列式形式）
$$\nabla\times\vec A=\begin{vmatrix}\hat a_x&\hat a_y&\hat a_z\\ \dfrac{\partial}{\partial x}&\dfrac{\partial}{\partial y}&\dfrac{\partial}{\partial z}\\ A_x&A_y&A_z\end{vmatrix}$$

展開後：

$$\nabla\times\vec A=\hat a_x\Big(\frac{\partial A_z}{\partial y}-\frac{\partial A_y}{\partial z}\Big)+\hat a_y\Big(\frac{\partial A_x}{\partial z}-\frac{\partial A_z}{\partial x}\Big)+\hat a_z\Big(\frac{\partial A_y}{\partial x}-\frac{\partial A_x}{\partial y}\Big)$$
推導邏輯（簡述，以 x 分量為例）

要算 x 分量，迴路要畫在垂直於 x 的平面，也就是 y-z 平面上。迴路四邊分兩組：一組平行 z 軸的邊（涉及 $A_z$ 隨 $y$ 的變化）、一組平行 y 軸的邊（涉及 $A_y$ 隨 $z$ 的變化）。兩組貢獻方向相反，相減後除以面積 $\Delta y\Delta z$，取極限得到 $\partial A_z/\partial y-\partial A_y/\partial z$。這跟散度不同的地方在於：旋度是「不同方向」的分量互相牽制、相減，因為環流本質是切向量繞圈，需要兩個方向的變化互相配合才轉得起來。

柱座標 / 球座標版本
柱座標
$$\nabla\times\vec A=\frac{1}{r}\begin{vmatrix}\hat a_r&r\hat a_\phi&\hat a_z\\ \dfrac{\partial}{\partial r}&\dfrac{\partial}{\partial\phi}&\dfrac{\partial}{\partial z}\\ A_r&rA_\phi&A_z\end{vmatrix}$$
球座標
$$\nabla\times\vec A=\frac{1}{R^2\sin\theta}\begin{vmatrix}\hat a_R&R\hat a_\theta&R\sin\theta\,\hat a_\phi\\ \dfrac{\partial}{\partial R}&\dfrac{\partial}{\partial\theta}&\dfrac{\partial}{\partial\phi}\\ A_R&RA_\theta&R\sin\theta\,A_\phi\end{vmatrix}$$

前面的係數 $1/r$、$1/(R^2\sin\theta)$，是該座標系「非直線距離」座標換算回實際弧長需要乘的尺度因子乘積，跟體積或表面積無關。

物理意義
  • 流體力學：$\vec A$ = 流速場，旋度代表流體在這一點的局部渦旋轉速（角速度的兩倍）
  • 磁場：$\nabla\times\vec B=\mu_0\vec J$（安培定律微分形式），電流密度 $\vec J$ 是磁場旋轉的源頭
  • 靜電場：$\nabla\times\vec E=0$，因為靜電場是梯度場（保守場），不會形成環流
數學意義

旋度衡量向量場在某一點的「旋轉傾向」，是向量，因為轉動需要指定轉軸方向，不同轉軸算出來的旋轉強度不一樣，所以三個方向分量各自代表繞不同軸轉動的強度。

對應的積分定理：斯托克斯定理
$$\oint_C\vec A\cdot d\vec\ell=\int_S(\nabla\times\vec A)\cdot d\vec S$$

封閉迴路的環流，等於內部旋度的面積分總和——邊界（1維曲線）上量到的東西，等於內部（2維曲面）微分量的積分。

跟另外兩者的關聯
$\nabla\times(\nabla V)=0$  ·  $\nabla\cdot(\nabla\times\vec A)=0$

梯度場的旋度恆為 0；旋度場的散度恆為 0——兩個 null identity 都跟旋度直接相關。

計算難度與注意事項排序

1 · Gradient最簡單，直接偏微分，不需要行列式
2 · Divergence次簡單，直接偏微分後相加；非卡氏座標要注意尺度因子在偏導數內部（不是外面乘）
3 · Curl最複雜，需要用行列式展開；非卡氏座標要注意行列式第一列與第三列都要乘尺度因子，且最前面還要除以尺度因子乘積
